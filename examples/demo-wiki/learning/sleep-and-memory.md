# Sleep and Memory

**Category:** learning
**Sources:** [[RAW/reading-notes.md]]
**Updated:** 2026-01-15
**Type:** article
**Confidence:** moderate

## Core Claim
Sleep consolidates what was learned during the day.

## Evidence
Studying a little before sleep and reviewing the next morning uses that consolidation. Pulling an all-nighter skips it.
