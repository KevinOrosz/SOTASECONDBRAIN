# Active Recall

**Category:** learning
**Sources:** [[RAW/study-guide.md]]
**Updated:** 2026-01-15
**Type:** article
**Confidence:** moderate

## Core Claim
Testing yourself strengthens memory more than rereading does.

## Evidence
Close the book and write down what you remember, then check. The effort of retrieval is the point; rereading only feels productive.
