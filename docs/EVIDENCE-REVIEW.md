# Review a revised source

Keep the approved RAW file and its incoming revision under different names. Run these commands from the repo root. Source arguments are paths within `KB/RAW`. Each command prints JSON. The examples use illustrative filenames and proposal IDs.

1. **Compare source revisions.** `bin/kb evidence diff handbook-v1.md handbook-v2.md` reports the SHA-256 of each file and changed line blocks. Offsets are zero-based. The removed and added arrays retain line endings, including a missing final newline.
2. **Find what needs review.** `bin/kb evidence impact handbook-v1.md` finds pages that cite that source in their Sources header or originating proposal. It follows reverse `Depends-On` links and returns one shortest declared chain per page, plus matching regression IDs and their status. It can trace a deleted source by its old path. Undeclared dependencies and semantic effects require human review.
3. **Check a quotation.** Save a one-based inclusive range with `bin/kb evidence pin handbook-v1.md 12 14 > /tmp/deadline-pin.json`. Run `bin/kb evidence check /tmp/deadline-pin.json --revision handbook-v2.md`. A unique match returns its new line number. A missing or repeated quotation exits 1. On the original bytes, the recorded range disambiguates duplicates. Comparison preserves line text and ignores newline encoding for quote matching. The receipt contains the quotation in plain text. It verifies the text at a location, not the meaning of the surrounding passage.
4. **Rehearse a proposed fix.** After creating an inbox proposal, run `bin/kb evidence rehearse AGENT/YYYY-MM-DD-slug "When is the deadline?" --k 8`. The command rebuilds search for the original and proposed wiki in temporary folders, prints both rankings and their changes, and verifies the proposal payload is still current before returning. A page entering the top results establishes a retrieval change. Answer correctness still requires replay and judgment. Rehearsal does not approve or land the proposal.

Use `bin/kb evidence --root /path/to/instance COMMAND ...` for another instance. An invalid request exits 2. No model calls or third-party dependencies are required.
