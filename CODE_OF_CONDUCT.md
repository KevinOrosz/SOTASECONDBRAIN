# Code of Conduct

Be kind, be specific, assume good intent. Critique ideas and code, never people. Harassment, insults and discrimination of any kind aren't tolerated.

Problems go to the repository owner privately. They'll respond, and may remove content or contributors that break this code.

This follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
